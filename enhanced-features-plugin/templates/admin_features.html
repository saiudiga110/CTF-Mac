Dynamic Scoring System

Advanced scoring calculations based on solve time and competition

0
Active Scores

Dynamic scoring adjusts points based on:

  • First-solve bonuses (+50 bonus points)
  • Rank-based adjustments (decreasing with solves)
  • Time-decay factors
  • Competition level scoring
API Endpoint:
POST /api/impl/scoring/calculate
Body: {challenge_id: int, user_id: int, base_points: int}
